# AI UGC Ad Content Pack for Arise GYM

## About the Project

This project explores how AI can be used to create marketing content for a real business. I chose **Arise GYM** as the example business and used AI tools to generate different types of advertisements for social media platforms.

The goal was to create content that feels authentic, engaging, and focused on attracting potential gym members.

---

## What This Project Includes

Using structured prompts, I generated:

* UGC-style ad scripts
* Scroll-stopping hooks
* Instagram captions
* Facebook ads
* YouTube Shorts scripts
* Brand voice variations
* Calls-to-action (CTAs)

---

## Tools Used

* ChatGPT
* GitHub
* Google Docs

---

## How I Created the Content

For each type of advertisement, I first designed a prompt with clear instructions.

The prompts included:

* The role the AI should play
* Information about the business
* The target audience
* The platform where the ad would be used
* The desired tone
* The structure of the final output

After generating the content, I reviewed the outputs and organized them into separate files.
